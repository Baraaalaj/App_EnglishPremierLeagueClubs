# ⚽️ English Premier League Clubs App

An interactive Android application that provides detailed information about **English Premier League clubs**.  
Developed in **Kotlin**, the app uses **RecyclerView** to display a list of clubs, with the ability to view detailed information for each club, including its image, description, history, achievements, and additional info.  
It also includes a button that redirects users to the club’s page on Google for more details.

## 🎯 Features

- Display a list of Premier League clubs using **RecyclerView**  
- View detailed information for each club:  
  - Club image  
  - Short description  
  - Club history  
  - Achievements  
  - Custom additional info  
- Redirect button to open the club’s Google page  
- Simple and clean design with **ViewBinding**  
- Load images dynamically using **Picasso**  

---

## ⚙️ Tech Stack

- **Kotlin** – main development language  
- **Android SDK 35** – development environment  
- **ViewBinding** – bind UI with code  
- **Picasso** – load images from the internet  
- **Material Design Components** – modern UI design  
- **RecyclerView** – display club list  

---

## 🚀 Getting Started

1. Open the project in **Android Studio**  
2. Ensure your `libs.versions.toml` file is configured correctly  
3. Run the app on an emulator or a physical Android device  
4. Make sure you have an internet connection for images and links
