# ⚽️ English Premier League Clubs App

تطبيق أندرويد تفاعلي يعرض معلومات مفصلة عن أندية الدوري الإنجليزي الممتاز. تم تطويره باستخدام Kotlin ويعتمد على RecyclerView لعرض قائمة الأندية، مع إمكانية استعراض تفاصيل كل نادي بشكل منفصل، بما في ذلك الصورة، الوصف، تاريخ النادي، الإنجازات، ومعلومات إضافية. كما يحتوي على زر ينقل المستخدم مباشرة إلى صفحة النادي على Google لمزيد من المعلومات.

## 🎯 الميزات

- عرض قائمة أندية الدوري الإنجليزي باستخدام RecyclerView  
- عرض تفاصيل كل نادي عند الضغط عليه:  
  - صورة النادي  
  - وصف مختصر  
  - تاريخ النادي  
  - الإنجازات  
  - معلومات إضافية مخصصة  
- زر ينقل المستخدم إلى صفحة النادي على Google  
- تصميم بسيط وسهل باستخدام ViewBinding  
- تحميل الصور باستخدام مكتبة Picasso

## ⚙️ التقنيات المستخدمة

- **Kotlin** – اللغة الأساسية للتطوير  
- **Android SDK 35** – بيئة التطوير  
- **ViewBinding** – لربط الواجهة بالكود  
- **Picasso** – لتحميل الصور من الإنترنت  
- **Material Design Components** – لتصميم واجهة المستخدم  
- **RecyclerView** – لعرض قائمة الأندية

## 🚀 طريقة التشغيل

1. افتح المشروع باستخدام Android Studio  
2. تأكد من إعداد ملف `libs.versions.toml` بشكل صحيح  
3. شغّل التطبيق على المحاكي أو جهاز Android حقيقي  
4. تأكد من وجود اتصال بالإنترنت لتحميل الصور والروابط

## 📦 حالة المشروع

المشروع جاهز ويعمل بكفاءة، مع خطط مستقبلية لإضافة ميزات مثل:

- البحث عن نادي معين  
- تصنيف الأندية حسب عدد البطولات  
- مشاركة معلومات النادي عبر وسائل التواصل  
- ربط التطبيق بواجهة API لجلب بيانات مباشرة
